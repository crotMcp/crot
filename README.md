# CROT

CROT is a universal local AI-agent bridge: an installable local bridge that gives
AI agents controlled or full access to the user's computer and browser through a
standard MCP interface.

`ARCHITECTURE.md` is the source of truth for the product architecture.

## Status

Early foundation. See `ARCHITECTURE.md` §16 for the development order.

## Requirements

- Node.js 20 or newer

## Development

```sh
npm install
npm run check   # typecheck + tests + build
```
