# CROT Control Center — implementation specification

## Owner directive — 2026-10-24 (takes precedence over the attached review)

- Full delegation: generate the SVG master in code from 01-login; no manual design prerequisite.
- Official domain: `crot.networking`; MCP/Relay endpoint: `https://mcp.crot.networking/relay/...`. Never migrate credentials or production deployments as a cosmetic change.
- Reference images live in `reference/`; historical alternatives 04/06 are not implementation targets.
- SVG masters: `assets/brand/crot-mascot.svg`, `crot-wordmark.svg`; all derivatives generated, not separately redrawn. Fill #FFC21A, stroke #1B2236, no gloss or shadows. Wordmark text is outlined.
- Local Inter Variable for UI; local JetBrains Mono Variable for URLs, paths, tokens, ports. Latin and Cyrillic, tabular numerals, no Google Fonts calls.
- Lucide UI icons, currentColor, stroke width 1.75, sizes 16/20/24; vendor logos from Simple Icons where available, neutral Lucide fallback otherwise. No vendor mark substitution.
- Sidebar: Home/house, Unified Chat/message-square, Agents & Tokens/bot, Projects/folder, Connectors/plug, Accounts/user-round, Permissions/shield-check, Browser/globe, Journal/scroll-text, Settings/settings. Ten entries total.
- Exact owner light/dark palette in `assets/brand/tokens.css`, one semantic source of truth; Light/Dark/System persist and apply before first paint, System follows OS changes.
- Sidebar 240px, collapsed 72px below 1100px; minimum desktop window 960×640. Native window frame. Long content remains scrollable.
- ARCHITECTURE.md and ExecutionGuard are authoritative. Conflicts with old UI decisions are registered in AD-42 and IMPLEMENTATION.md, not silently bypassed. Never simulate OAuth, chat generation, publication, token rotation, provider revocation or active subscriptions.
- Existing startup Auth → Plans → Home and verified commercial admission remain. Preserve guarded tool routes as contextual navigation.

## Attached review (planning material, subordinate to directive and architecture)

CROT Control Center — ТЗ по дизайн-системе, оценка цены $3 и план реализации
Oct 24, 2026 · @kos
Кратко
Макеты годятся как визуальная основа, но не как готовая спецификация: в них есть ошибки, которые агент не должен копировать, и три разных стиля иконок вместо одного.
• Дизайн. Единый логотип (один SVG-мастер), один набор линейных иконок, два шрифта (Inter и JetBrains Mono, оба с кириллицей) и общие токены цвета для светлой и тёмной темы. Всё это описано в разделе «Единая дизайн-система».
• Цена $3. Как ежемесячная подписка это слабая модель: на таком чеке платёжный сервис забирает 13–22%, а Stripe в Украине напрямую недоступен. Рабочие варианты: годовой тариф около $29–39 или «цена основателя» для первых пользователей.
• Главный риск — не дизайн, а площадки. TikTok оставляет публикации неаудированных приложений приватными и требует держать секрет приложения конфиденциальным, у Midjourney нет официального API, а Bearer-токен Relay даёт полный доступ к CROT. Пока эти три вопроса не решены, Pro-тариф обещает то, что не работает.
• Порядок работ. Сначала ты готовишь логотип, шрифты и аккаунты (раздел 2). Затем агент вводит токены и компоненты, потом экраны, потом безопасность и релизную инфраструктуру, и только в конце подписку.
Что нужно сделать тебе
На тебе пять блоков, и до них агент не должен верстать финальные экраны: логотип, шрифты и иконки, продуктовые решения, аккаунты с платежами и материалы для агента.
Логотип (блокирует остальное)
[ ] Выбрать один эталон маскота. Самый чистый вариант на экране входа: плоский, с толстым тёмным контуром. На других скриншотах маскот нарисован иначе (пропорции, глянец, тень), то есть это уже несколько разных логотипов.
[ ] Получить векторный мастер. Нужны два SVG: маскот и надпись «CROT» с текстом, переведённым в кривые. Их делает дизайнер, трассировка в Inkscape или Illustrator, либо ручная перерисовка. Я не могу нарисовать маскота, а агенту нельзя «перерисовывать по скриншоту»: получится ещё один вариант. Файлы кладутся в assets/brand/.
[ ] Утвердить производные. Агент сгенерирует их скриптом из мастера: иконка приложения 1024×1024 (.icns, .ico, PNG), монохромная иконка трея (16, 22, 32 px), иконки расширения (16, 32, 48, 128 px), favicon. Тебе нужно посмотреть один лист на светлом и тёмном фоне.
Шрифты и иконки
[ ] Шрифты: Inter (интерфейс) и JetBrains Mono (токены, пути, код). У обоих есть кириллица и лицензия SIL OFL. Ставятся пакетами @fontsource-variable/inter и @fontsource-variable/jetbrains-mono, так что шрифты лежат внутри приложения и работают без интернета. Тебе нужно только согласиться с выбором.
[ ] Иконки интерфейса: Lucide (лицензия ISC). Один линейный набор вместо трёх стилей на скриншотах: плоские цветные, объёмные и линейные.
[ ] Логотипы сторонних сервисов (Notion, Claude, OpenAI, YouTube, TikTok, ElevenLabs, n8n): брать из официальных brand-kit этих сервисов или из Simple Icons, не рисовать самим и не вырезать со скриншотов. Права на эти знаки у их владельцев, поэтому их можно показывать только как названия подключаемых сервисов.
Решения по продукту
[ ] Убрать Midjourney из каталога. Официального API нет, а условия сервиса запрещают автоматический доступ; обёртки третьих сторон рискуют блокировкой аккаунта пользователя (источник).
[ ] Выбрать модель публикации в TikTok, Instagram и X. Варианты и рекомендация для первой версии описаны в разделе «Коммерция».
[ ] Подтвердить тарифную сетку. Годовой план вместо одного тарифа $3 в месяц, обоснование там же.
[ ] Оставить песочницу L1 в бесплатном тарифе. Сейчас в сравнении тарифов она значится как функция Pro, а безопасность по умолчанию не должна быть платной.
Аккаунты и платежи
[ ] Merchant of Record для приёма платежей (Paddle, Lemon Squeezy или Polar). Stripe недоступен для бизнеса в Украине: страница stripe.com/global её не содержит.
[ ] Подпись приложений. Apple Developer Program (около $99 в год, по моим данным, проверь), сертификат подписи кода для Windows и разовый взнос Chrome Web Store для расширения (около $5, проверь). Без подписи ОС показывает предупреждения при установке.
[ ] Домен и название. В макете уже есть mcp.crot.networking: убедись, что домен crot.networking зарегистрирован на тебя, и проверь, не занято ли название CROT как торговая марка в классе ПО.
[ ] Документы. Terms of Service и Privacy Policy: ссылки на них уже есть в «Настройках», страницы должны существовать к релизу.
Материалы для агента
[ ] Положить скриншоты в docs/design/reference/ под именами 01-login, 02-plans, 03-home, 04-home-old, 05-chat, 06-chat-old, 07-agents-tokens, 08-projects, 09-connectors-local, 10-connectors-web, 11-accounts, 12-permissions, 13-browser, 14-settings, а этот документ как docs/design/SPEC.md.
[ ] Сказать агенту два правила. Если макет противоречит ARCHITECTURE.md, главнее ARCHITECTURE.md, а расхождения идут списком вопросов, не молчаливой правкой. И сервисы не хардкодятся в Core: каталог коннекторов задаётся данными.
Единая дизайн-система
Дизайн-система CROT состоит из одного логотипа, двух шрифтов, одного набора линейных иконок и общих токенов цвета. Агент вводит токены раньше любых компонентов и экранов. Скриншоты задают компоновку, а значения берутся из этого раздела: при расхождении он главнее.

ТЗ агенту
Агент реализует интерфейс в пять шагов: токены, компоненты, оболочка, экраны, проверка. Ниже общие правила, спецификация оболочки, экранов и диалога публикации. Номера экранов совпадают с именами файлов 01–14.
Общие правила
1. Порядок работ: токены и шрифты, базовые компоненты, оболочка (окно, сайдбар, шапка), экраны по порядку, визуальные тесты.
2. Значения берутся из раздела «Единая дизайн-система», а скриншоты служат референсом компоновки. Исправления из раздела «Ошибки на текущих макетах» обязательны.
3. Каждая строка интерфейса — ключ i18n с переводами RU и EN. Строк в коде нет.
4. Сервисы, коннекторы и интеграции — данные (манифесты), а не код в Core. При расхождении с ARCHITECTURE.md главнее ARCHITECTURE.md.
5. У каждого экрана есть состояния: загрузка (skeleton), пусто, ошибка с действием «Повторить» и «локальный мост недоступен».
6. Секреты (ключи API, Bearer-токен, сессия) хранятся в системном хранилище: Keychain на macOS, Credential Manager на Windows, Secret Service на Linux. Они не попадают в логи, localStorage и конфиг-файлы, а в интерфейсе маскируются.
7. Минимальный размер окна 960×640. При ширине меньше 1100 px сайдбар сворачивается до иконок (72 px).
8. Проверка: снимки экранов в светлой и тёмной теме на RU и EN, автоматическая проверка контраста и доступности (axe), переключение темы без перезагрузки.
Оболочка
• Окно. Нативная рамка ОС, заголовок «CROT Control Center».
• Сайдбар, 240 px. Горизонтальный логотип и девять пунктов в порядке: Главная, Единый чат, Агенты и токены, Проекты, Коннекторы, Аккаунты, Разрешения, Браузер, Настройки. Бейдж «Live» у чата показывает реальное состояние (Live зелёным, Offline нейтральным), а не статичный текст. Внизу блок статуса моста (см. раздел «Чего не хватает и что лишнее»).
• Шапка. Колокольчик открывает центр уведомлений и очередь подтверждений действий агентов. Аватар открывает меню: аккаунт, подписка, выход. Рядом плашка плана.
Экраны
01 Вход
• На экране: полный логотип, поле email, кнопка «Создать аккаунт», ссылка «Войти», кнопки Google и GitHub, переключатель языка.
• Логика: на макете только email, поэтому предлагается вход одноразовым кодом из письма, без пароля (решение Kos). Google и GitHub открывают системный браузер и возвращаются через loopback или deep link; встроенный webview не используется.
• Приёмка: ошибка email показывается под полем; токен сессии лежит в системном хранилище.
02 Выбор тарифа
• На экране: карточки Free и Pro с бейджем «7 дней бесплатно» и панель «Почему CROT Pro?».
• Состояния: если пробный период уже использован, кнопка называется «Оформить Pro», бейдж скрыт. План можно сменить позже в «Настройки → Подписка».
• Оплата: страница платёжного сервиса в системном браузере; статус возвращается в аккаунт вебхуком.
• Приёмка: после оплаты план в приложении обновляется без перезапуска; отмена пробного периода занимает один клик.
03 Главная
• На экране: маскот по центру, четыре карточки категорий (облачные AI, видео-завод, премиум-API, песочница) в цветах категорий, баннер плана внизу.
• Логика: карточки ведут в свои разделы. Баннер плана подчиняется правилу №10 из раздела ошибок. Эталон — макет 03.
• Приёмка: маскот и плитки сохраняют контраст в тёмной теме.
05 Единый чат
• На экране: пустое состояние с четырьмя стартовыми запросами, два селектора над полем ввода, поле сообщения, прикрепление файла, строка облачных агентов со статусом.
• Селекторы получают подписи «Платформа» (слева) и «Инструмент» (справа). Сейчас непонятно, на что они влияют.
• Отправка: ⌘+Enter на macOS, Ctrl+Enter на Windows и Linux; Enter переносит строку.
• Лента: потоковый ответ, кнопка «Остановить», вызовы инструментов отдельными блоками, запросы подтверждения прямо в ленте.
• Приёмка: агент без соединения показан серым с причиной; файл сверх лимита отклоняется понятным текстом.
07 Агенты и токены
• Левая колонка: Relay URL и Bearer-токен как секретные поля; «Сгенерировать новый токен» с диалогом «прежний токен перестанет работать»; плитки Notion, Claude, n8n открывают пошаговую инструкцию с кнопкой «Скопировать конфигурацию».
• Правая колонка: Cloud LLM (провайдер, ключ, «Сохранить и проверить»), Local Models (URL и порт, «Проверить»), Workspaces (статус, «Настроить», OAuth).
• Приёмка: «Подключено» появляется только после реальной проверки и показывает её время; ключи уходят в системное хранилище; токен можно перегенерировать и отозвать.
08 Проекты
• Три колонки: выбор проекта, автообнаружение среды, песочница и разрешения.
• Папка выбирается системным диалогом. У пунктов «Недавние» есть меню «⋯»: открыть, убрать из списка, показать в файловом менеджере.
• Автообнаружение: стеки, активные порты, дерево с ленивой загрузкой; секреты отмечены замком (ошибка №4).
• Лимит Free: счётчик «2 из 3»; при четвёртом проекте баннер апгрейда.
• Приёмка: L1-изоляция ограничивает агента корнем проекта: попытка прочитать файл выше корня отклоняется и попадает в журнал.
09 и 10 Коннекторы
• Две вкладки: «Локальные скиллы» и «Web-сервисы». Карточки в единой сетке, статус-плашка, «Автопоиск в системе»; версия определяется запуском с флагом версии.
• «Добавить коннектор»: «Выбрать из каталога» и «Создать Custom Skill»; каталог собирается из манифестов.
• Ключи: секретные поля с «Сохранить и проверить». Midjourney в каталоге нет, Remotion устроен по ошибке №8.
• Приёмка: новый сервис добавляется манифестом, без правки кода экрана.
11 Аккаунты
• Карточки платформ: YouTube, TikTok, X, Instagram и GitHub.
• Состояния карточки: не подключён, подключён (аватар и @имя), нужна повторная авторизация, ограничен (например, публикации будут приватными).
• Публикация идёт только через диалог публикации (ниже). Для TikTok и Instagram публикация без подтверждения человека не допускается.
• Приёмка: отключение аккаунта отзывает токен у платформы, а не только удаляет его локально.
12 Разрешения
• Строгий режим (Strict Mode): при включении все действия агентов требуют подтверждения, остальные строки блокируются и показывают «По запросу».
• Три режима у каждой строки: «Автоматически», «По запросу», «Запрещено». Третьего в макете нет, но он нужен для опасных действий.
• Приёмка: смена режима действует сразу на уже работающих агентов; каждое решение пишется в журнал действий.
13 Браузер
• Статус расширения: подключено, отключено, версия несовместима; кнопка «Управление расширением».
• Область действия: группа с выбором одного режима (ошибка №3). Cookies и автоклики выключены по умолчанию.
• Чёрный список: пресет «Финансы и платежи» вместо жёстко прописанных значений; список редактируется.
• Приёмка: расширение отказывается работать на доменах из чёрного списка, это проверяет автотест.
14 Настройки
• Язык (RU и EN) и тема (светлая, тёмная, системная) применяются сразу. Автозапуск, работа в трее и аппаратное ускорение; у последнего пометка «нужен перезапуск».
• «Очистить кэш» с подтверждением и «Экспорт логов» с маскированием секретов.
• «О программе»: версия, проверка обновлений (обновления подписаны), ссылки на условия, политику конфиденциальности и документацию.
• Новый блок «Подписка»: план, дата продления, отмена, чеки.
Диалог публикации
Диалог один для всех платформ и строится по правилам TikTok как самым строгим (TikTok Content Sharing Guidelines). Агент не отправляет материал, пока человек явно не подтвердил его здесь. Водяные знаки и рекламные надписи к материалу не добавляются.
• Аккаунт-получатель: ник или название канала.
• Предпросмотр публикации и редактируемые заголовок и описание.
• Приватность: выпадающий список без значения по умолчанию. Для TikTok варианты берутся из ответа платформы.
• Комментарии, дуэт и склейка выключены по умолчанию; недоступные платформе опции неактивны.
• Раскрытие коммерческого контента выключено по умолчанию. При включении надо выбрать «свой бренд» или «брендированный контент», пока выбора нет, кнопка публикации заблокирована.
• Текст согласия с условиями платформы перед кнопкой «Опубликовать».
• Статус после отправки: в очереди, обработка, опубликовано, ошибка; платформа опрашивается.
Приватность выбирается явно и для YouTube: если не указать её, видео по документации публикуется как публичное (YouTube Data API, videos.insert).
Чего не хватает и что лишнее
В меню не хватает того, что делает продукт с доступом к файлам и браузеру безопасным и понятным: журнала действий, очереди подтверждений, аварийной остановки, первого запуска и подписки. Лишнее — то, что размывает позицию продукта или создаёт юридические риски.

Конкуренты и позиция
Ниша существует, но «просто мост» бесплатен: локальные MCP-серверы подключаются к Claude Desktop напрямую, агрегаторы вроде 1MCP сводят их в один прокси, а браузерные расширения с relay уже есть в открытом виде (Vibe MCP: расширение соединяется с relay, и любой клиент управляет браузером по URL с идентификатором). По моей оценке платят за другое: за доверие (песочница, журнал, подтверждения), за удалённый доступ без настройки сети и за готовые сценарии. Из этого и строится позиция.
Вердикт
Продавать за $3 можно, если выполнены четыре условия: цена показывается как годовая, стоимость relay на пользователя измерена, публикации в соцсети не обещаются там, где площадки этого не разрешают, и безопасность остаётся бесплатной. Нельзя, если $3 в месяц единственный вариант и обещана автопубликация везде: возвраты и поддержка будут стоить дороже, чем приносит чек.
План реализации
План состоит из шести фаз, и каждая закрывается проверяемым условием: следующая начинается только после него. Безопасность строится раньше остальных экранов, потому что на ней держится продажа продукта.
Сроков в плане нет намеренно: размер кодовой базы мне неизвестен. Агент даёт оценку по фазам после фазы 1, когда виден реальный объём работ.
