# Security policy

## Supported versions

The current stable release and protocol-compatible versions within the documented 12-month window receive security fixes. Exact version/EOL dates are published at `[SECURITY ADVISORY URL]`; development snapshots and modified builds are unsupported.

## Reporting

Do **not** open a public issue for a suspected vulnerability. Send it through `[SECURITY EMAIL/FORM]` with the affected version, component, impact and minimal reproduction. Never send production secrets, access tokens, device private keys, private files or unrelated personal data. The full coordination and safe-harbor policy is in [docs/legal/VULNERABILITY_DISCLOSURE.md](docs/legal/VULNERABILITY_DISCLOSURE.md).

For non-security help use [docs/SUPPORT.md](docs/SUPPORT.md). Availability incidents appear at `[STATUS PAGE URL]`.
