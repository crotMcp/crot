## Last completed

**WP-19 — Remote MCP request pipeline per AD-15** (ARCHITECTURE.md §27
AD-15 points 3, 6, 7, 8; constraints C1–C3, C5, C8).

- **SDK decision.** The SDK v1 line (`@modelcontextprotocol/sdk` 1.31/1.32)
  does not support 2026-07-28. CROT now uses both official lines: SDK v1 for
  stdio and the legacy session versions 2025-11-25 / 2025-06-18, SDK v2
  (`@modelcontextprotocol/server` `createMcpHandler`) for sessionless
  2026-07-28 requests, on the same `/mcp` endpoint, distinguished by the
  protocol version (C3). Core is not affected. A full move to SDK v2 is a
  follow-up.
- **Sessionless requests.** No `initialize`, no `Mcp-Session-Id`, header–body
  validation (`-32020`), `server/discover`, 405 for GET/DELETE; one MCP
  server instance and one execution context per request; the request signal
  cancels pending approvals and running operations. Unsupported versions
  (header, `_meta`, legacy `initialize`) are rejected with `400` / `-32022`.
- **Principals.** The entry point decides the kind: stdio and loopback HTTP
  are `local`, the relay entry point (pipeline only; tunnel WP-30) is
  `remote` with `accountId`, `deviceId`, `clientId` and never accepts the
  local token. Rules with `principalKinds: ["remote"]` no longer match
  loopback clients (README: migration).
- **Exposure scopes.** `ExposureTracker` is keyed by the exposure scope:
  stdio connection and legacy session as before, sessionless loopback per
  principal, remote per (account, device, client), persisted as digests in
  `<state>/remote-exposure.json` (protected path), failing closed when it
  cannot be read; no reset (WP-22).
- **Request id.** Generated by the adapter (UUID) per tool call.
- **C1.** PermissionEngine, ExecutionGuard, approval broker and tools are
  unchanged. Every MCP execution context carries a `session` that never spans
  more than one exposure scope (stdio connection, legacy session, or the
  single sessionless request), so the guard's per-session exposure snapshots
  (AD-12 point 10) keep working unchanged.

Tests: `tests/adapters/http-modern.test.ts`,
`tests/core/remote-exposure.test.ts`, `tests/adapters/invoke.test.ts`; updated HTTP, approval-gate and
session-exposure tests.
